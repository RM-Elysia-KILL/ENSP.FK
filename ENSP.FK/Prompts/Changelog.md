# ENSP.FK 更新公告

## v1.0.5 — 2026-05-29

### 自适应界面重写
- 全面采用 Viewbox 自适应布局，所有页面根据窗口大小等比缩放
- 缩放方向设为 UpOnly，窗口小时保持最小尺寸不缩水，窗口大时等比放大
- 窗口缩放时实时重新计算 UI 比例，无需重启
- 内容宽度统一适配窗口最小宽度 800px，杜绝裁切

### 设备管控优化
- 移除"停止全部"按钮，简化操作流程
- 操作按钮分为「设备管控」和「配置操作」两组，默认展开可按需折叠
- 分组采用卡片式边框，视觉层次更清晰

### Scale 标记扩展完善
- 修复 {helpers:Scale} 在 ColumnDefinition（GridLength）上类型转换崩溃的问题
- 修复 {helpers:Scale} 在 DataGridColumn（DataGridLength）上设置失败的问题
- 改用 IProvideValueTarget 自动检测目标属性类型，返回正确的 WPF 值类型

### 已知问题修复
- 修复设备连接取消/异常时 UI 状态卡在"等待就绪"的问题
- 修复拓扑接口扩展块数量异常时插槽号分配错误的问题
- 修复测试连接后 API 配置不持久化到磁盘的问题
- 修复 4 个 XAML 文件 helpers 命名空间声明位置导致编译失败的问题
