# ENSP.FK 更新公告

## v1.0.4 — 2026-05-27

### 全新设备管控
- 设备管控面板全面重写，采用直接 Telnet 连接架构
- 设备列表显示实时状态（离线/启动中/就绪/错误）、进度条、状态描述
- 支持单设备连接/断开、批量连接/断开、批量配置推送
- 终端采用深色背景 + 圆角设计，绿色提示符，VS Code 风格

### 一键部署优化
- 一键部署按钮移至工具栏（打开拓扑右侧），操作更便捷
- 未导入需求时按钮自动禁用，悬停显示提示
- 部署流程：连接设备 → 进入 system-view → 推送命令 → 保存配置，全自动

### AI 配置生成增强
- 新增防火墙 USG/NGFW 规则（安全区域、安全策略、NAT 策略）
- 新增终端设备 PC/Server 规则（DHCP、静态 IP、网关、DNS、IPv6）
- 新增接口管理规则（description、shutdown、hybrid 模式）
- 新增设备角色边界约束，防止 AI 误配

### UI 优化
- 表单字段增加标签和占位提示
- 需求配置输入框固定高度，内部滚动
- 一键部署完成后弹出结果提示框
- 窗口最小尺寸约束，缩放不裁切
- 验证审核标注"正在完善，暂时无用"
- 各 Section 间距收紧，整体更紧凑

### 已知问题修复
- 修复 AI 生成接口名 GE 0/0/0 含空格的问题
- 修复一键部署首次点击连接失败（race condition）
- 修复禁用按钮不显示 ToolTip 的问题
- 修复窗口缩小后界面裁切问题
